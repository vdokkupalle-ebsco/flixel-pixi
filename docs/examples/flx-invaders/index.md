# Flx-Invaders (AS3 Compatibility Port)

A clean-room compatibility port of AdamAtomic's classic **Flx-Invaders** game written in TypeScript on PixiJS v8.

## Highlights

- Pinned compatibility with the original ActionScript 3 Flixel baseline.
- Alien fleet movement, projectile groups, explosion particle emitters (`FlxEmitter`), and retro arcade score tracking.
- Audio synthesis and sound effects using `FlxAudioManager`.
