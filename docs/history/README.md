# Historical engineering records

This directory preserves the chronological records used while porting Flixel
from AS3. Current documentation is organized by engine capability; these files
remain available for provenance, benchmark context, and architectural review.

- [`porting/`](porting/README.md) — original roadmap and milestone evidence.
- [`implementation-plans/`](implementation-plans/) — detailed design and
  execution notes produced during implementation.

Historical files intentionally retain their original milestone terminology.
They should not be used as the current product roadmap.
