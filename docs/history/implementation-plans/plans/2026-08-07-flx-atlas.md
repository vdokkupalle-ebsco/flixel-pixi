# FlxG.atlas + Unified Sprite Animation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `FlxG.atlas` (XML / JSON / fixed-grid load + frame pickers) and unify `FlxSprite.addAnimation` / `play` so strip indices and atlas frames share one API, with `play(name, { loop, speed, force })` (`loop` default false, `speed` default 1).

**Architecture:** `FlxAtlasRegistry` on context (like `FlxG.actions`). Parsers build an ordered `FlxAtlas` of named Pixi texture regions. Atlas-backed `addAnimation` bakes those regions into a horizontal strip for existing index-based `FlxAnim`. `play` accepts a boolean (legacy) or options object; playback applies loop/speed without requiring separate create/play helpers.

**Tech Stack:** TypeScript, PixiJS v8 (`Texture`), existing `FlxSprite` / `FlxAnim` / `FlxG` context services, Vitest (happy-dom), API extractor.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-07-flx-atlas-design.md` — prefer spec on conflict.
- Work on **`main`** unless the user asks otherwise.
- **0-based** `framesByNumber` indices.
- Prefix `padding` must be `>= 1` (reject 0).
- No runtime atlas packing; no Spine; do not remove strip `loadGraphic`.
- Preserve legacy `addAnimation(name, frames, frameRate, looped)` and `play(name, force: boolean)`.
- No public `createAnimation` / `playAnimationLoop` / `toStrip`.
- Kenney sample migration is a **follow-up task** in this plan (optional last task) — engine first.
- Commit per task with HEREDOC messages; do not push unless asked.
- `npm run typecheck`, targeted vitest, and `api:update` (or `api:check` after report) must stay green for touched public API.

```ts
export interface FlxAtlasPrefixOptions {
  readonly padding?: number; // default 1, must be >= 1
}

export interface FlxAtlasFrame {
  readonly name: string;
  readonly texture: Texture;
  readonly index: number;
}

export type FlxAtlasFrameList = readonly FlxAtlasFrame[];

export class FlxAtlas {
  readonly key: string;
  readonly texture: Texture;
  getFrame(name: string): FlxAtlasFrame;
  framesByPrefix(
    prefix: string,
    start: number,
    end: number,
    options?: FlxAtlasPrefixOptions,
  ): FlxAtlasFrameList;
  framesByNumber(start: number, end: number): FlxAtlasFrameList;
  framesByNumber(indices: readonly number[]): FlxAtlasFrameList;
}

export type FlxAtlasGridMeta = {
  readonly frameWidth: number;
  readonly frameHeight: number;
};
export type FlxAtlasMeta = string | FlxAtlasGridMeta;

export class FlxAtlasRegistry {
  load(key: string, imageUrl: string, meta: FlxAtlasMeta): Promise<FlxAtlas>;
  get(key: string): FlxAtlas;
  has(key: string): boolean;
  remove(key: string): void;
  clear(): void;
}

/** Bake frames left-to-right; null cell = transparent (optional, internal OK). */
export function bakeAtlasFrameStrip(
  source: CanvasImageSource,
  frames: readonly { x: number; y: number; width: number; height: number }[],
  outW: number,
  outH: number,
): Texture;
```

`FlxG.atlas` mirrors `actions`:

```ts
static get atlas(): FlxAtlasRegistry {
  let instance = FlxG.context.getService<FlxAtlasRegistry>(FLX_ATLAS_SERVICE);
  if (instance === undefined) {
    instance = new FlxAtlasRegistry();
    FlxG.context.setService(FLX_ATLAS_SERVICE, instance);
  }
  return instance;
}
```

**`load` algorithm:**

1. Load image (`Image` + `decode`, or Pixi `Assets.load` → drawable).
2. If `meta` is string: `fetch` text; if `.json` or parses as JSON object → `parseTextureAtlasJson`; else → `parseTextureAtlasXml`.
3. If `meta` is grid → `parseFixedGridAtlas(img.width, img.height, …)`.
4. Build `Texture` base; for each rect create frame texture via `new Texture({ source: base.source, frame: new Rectangle(x,y,w,h) })` (Pixi v8 API — verify against installed pixi types).
5. Store `FlxAtlas` under `key` (overwrite or throw on duplicate — **prefer overwrite** with replace).

**Pickers:**

- `getFrame`: exact name, else `name + '.png'`, else throw.
- `framesByPrefix`: `padding = options?.padding ?? 1`; if `padding < 1` throw; for `n` in start..end inclusive build `prefix + padStart`; resolve via `getFrame` logic.
- `framesByNumber`: 0-based; range validates `start<=end`; array validates each index.

**Interfaces:**

- Consumes: `FlxAtlasFrameList`, `bakeAtlasFrameStrip`
- Produces: overloaded `addAnimation` / `play` per spec §8

**Playback state on sprite** (private fields):

```ts
#playbackLoop = true;
#playbackDelay = 0; // seconds per anim frame; 0 = freeze on frame 0 like today
```

`updateAnimation` must use `#playbackLoop` / `#playbackDelay` instead of only `animation.looped` / `animation.delay`.

**`addAnimation` dispatch:**

```ts
addAnimation(
  name: string,
  frames: readonly number[] | FlxAtlasFrameList,
  frameRate = 0,
  looped = true,
): void
```

- Detect atlas list: `Array.isArray(frames) && frames[0] && typeof frames[0] === 'object' && 'texture' in frames[0]`.
- Atlas path: determine `outW/outH` from first frame texture width/height (or frameWidth); bake strip; `loadGraphic(strip, true, false, outW, outH)`; indices `0..n-1`; defaults for **new-style** when only 2 args used: if `arguments.length === 2` → `defaultLoop=false`, `defaultSpeed=1`; if legacy 3/4 args with number[] → existing defaults.
- Practical overload detection: if `frames` is atlas list, ignore frameRate/looped for strip validation; set `defaultLoop=false`, `defaultSpeed=1` unless we add options later.
- Replace existing anim with same name (remove old from `#animations`).

**`play`:**

```ts
play(name: string, forceOrOptions: boolean | FlxAnimationPlayOptions = false): void
```

- Boolean → legacy force; apply anim defaults for loop/speed.
- Object → `loop = opts.loop ?? false`, `speed = opts.speed ?? 1`, `force = opts.force ?? false`; `speed <= 0` → `RangeError`.
- `delay = 1 / (FlxG.updateFramerate * speed)`.
